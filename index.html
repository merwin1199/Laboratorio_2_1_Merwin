Objetivo

Aprender a utilizar herramientas para crear, probar y administrar páginas web mediante HTML, CSS, Git y GitHub.

Herramientas utilizadas

  • Visual Studio Code para escribir y editar código.
  • Google Chrome para probar la página web.
  • Mozilla Firefox para comparar la visualización.
  • Git para controlar las versiones del proyecto.
  • GitHub para almacenar el proyecto en línea.

Desarrollo web

HTML permite organizar el contenido de una página web, mientras que CSS se utiliza para definir su apariencia. Los navegadores permiten comprobar su funcionamiento.

Prueba de control de versiones en Git.

Conclusión

En esta actividad se creó una página web básica y se practicó el uso de herramientas de desarrollo y control de versiones. Estas herramientas ayudan a organizar el trabajo y registrar los cambios realizados en un proyecto.
